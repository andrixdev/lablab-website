# LABLAB

Static website for LABLAB, a digital arts lab and immersive studio in Lyon, France. English at the root, French in `fr/`.
Open `index.html` in a browser — no build step. Pushing to `master` deploys to https://alexandrix.com/lablab-new/.

See [AGENTS.md](AGENTS.md) and [docs/](docs/PROJECT_CONTEXT.md).
